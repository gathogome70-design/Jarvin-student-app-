# Jarvin Student App

A mobile-friendly student life dashboard for managing money, study tasks, household chores, and student-entered school or personal timetables. Designed with Kenyan students in mind, with balances shown in Kenyan shillings (KSh).

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required. The app saves changes in that browser using `localStorage`.

## Features

- Overview dashboard with balance, tasks, upcoming plans, and the weekly class timetable.
- Money tracker for recording income and expenses, with a monthly budget snapshot.
- Study planner and chore list with due dates and completion toggles.
- Weekly Monday–Friday timetable for school classes and personal activities.
- Responsive desktop and mobile layouts.

## Notes

The initial data is sample content for demonstration. Data is stored locally in the browser; it is not synced between devices or connected to M-Pesa or a bank.
